# Day 3 – Exploratory Data Analysis (EDA)

## Overview
This practical focuses on Exploratory Data Analysis (EDA) using Python. The objective is to understand a dataset through summary statistics, data distributions, correlation analysis, and visualizations.

## Tools and Libraries Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

## Dataset
**File:** `students.csv`

The dataset contains student information with the following columns:
- Student_ID
- Name
- Age
- Department
- Marks

Dataset size: 8 rows and 5 columns.

## Tasks Performed

1. Loaded and explored the dataset using Pandas.
2. Checked dataset shape, data types, and statistical summary.
3. Identified missing values.
4. Analyzed department-wise student counts.
5. Studied marks and age distributions.
6. Performed correlation analysis between Age and Marks.
7. Compared marks across departments using a box plot.

## Visualizations Created
- Bar Chart – Department-wise student count.
- Histogram – Distribution of student marks.
- Histogram – Distribution of student ages.
- Correlation Heatmap – Relationship between numerical variables.
- Box Plot – Marks comparison across departments.

## Key Observations
1. The dataset contains 8 student records and 5 columns.
2. One missing value was identified in the Age column.
3. One missing value was identified in the Marks column.
4. Student marks range from 65 to 95.
5. The visualizations help understand department distribution, marks variation, and relationships between numerical variables.

**Note:** Correlation indicates a relationship between variables but does not necessarily establish causation.

## Learning Outcomes
- Gained practical experience in Exploratory Data Analysis.
- Learned to analyze data distributions and class counts.
- Understood correlation versus causation.
- Practiced creating and interpreting visualizations using Matplotlib.
- Developed the ability to identify evidence-based observations from data.
