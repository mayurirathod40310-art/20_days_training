
# CSV Row Counter

## About the Project
CSV Row Counter is a simple Python project that reads a CSV file and counts the total number of data rows, excluding the header.

## Project Structure

CSV_Row_Counter/
- data/
  - students.csv
- main.py
- requirements.txt
- .gitignore
- README.md

## Technologies Used
- Python 3.13.7
- Git
- CSV module
- pathlib module

## How to Run

1. Clone or download the project.
2. Create and activate a virtual environment.
3. Run the following command:

   python main.py

## Expected Output

CSV File: students.csv
Total Rows: 4
