# Day 4: Statistics, Splits and Data Leakage

## Objective
To understand statistical measures, perform proper train-test splitting, and identify potential data leakage in a sample dataset.

## Topics Covered
- Mean, Median and Variance
- Data Distribution
- Train-Test Splitting
- Stratified Sampling
- Reproducibility using random_state
- Duplicate Detection
- Data Leakage and Prevention

## Tools and Libraries
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn

## Practical Implementation
1. Created a sample student dataset.
2. Calculated mean, median and variance.
3. Examined Pass/Fail class distribution.
4. Performed an 80:20 stratified train-test split.
5. Checked duplicate records and missing values.
6. Checked for overlapping Student IDs between training and testing sets.
7. Documented the split strategy and leakage prevention methods.

## Project Files
- `day4_data_audit.ipynb` – Practical implementation.
- `sample_dataset.csv` – Sample dataset.
- `split_strategy_note.md` – Train-test splitting strategy.
- `leakage_checklist.md` – Data leakage audit checklist.

## Conclusion
Successfully performed statistical analysis and dataset splitting. Learned how stratified sampling, reproducibility and leakage checks contribute to reliable machine learning evaluation.
